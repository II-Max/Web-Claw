# Nâng Cấp Toàn Diện Web-Claw — Công Cụ Cào Dữ Liệu Web

## Tổng quan

Dự án hiện tại (DataMine V5) có nền tảng code tốt nhưng tồn tại nhiều **vấn đề nghiêm trọng** ngăn nó hoạt động thực tế:

1. **Import paths bị hỏng** — Code sử dụng `from web_miner.core...` nhưng project folder tên `Web-Claw` và không có package `web_miner`. File `app` là file rỗng 4 bytes thay vì thư mục.
2. **Chỉ hỗ trợ static HTML** — Sử dụng `requests` thuần, không thể cào các website render bằng JavaScript (React, Angular, Vue...).
3. **Không có anti-detection** — Không random User-Agent, không delay, không proxy → dễ bị chặn.
4. **Thiếu hỗ trợ auth/cookies** — Không thể cào website yêu cầu đăng nhập.
5. **Chỉ xuất Markdown + JSON** — Thiếu CSV/Excel thông dụng.
6. **Chỉ cào 1 trang** — Không crawl multi-page/pagination.

### Phase 2: Nâng Cấp Scraper — Hỗ Trợ Đa Định Dạng & Bảo Mật

#### [MODIFY] [scraper.py](file:///home/ii-max/Documents/Web-Claw/core/scraper.py) — Nâng cấp toàn diện

**2a. Headless Browser (Playwright)**
- Thêm fallback: thử `requests` trước → nếu nội dung trống/ngắn hoặc user chỉ định → chuyển sang Playwright
- Playwright cho phép cào website render JS (SPA), xử lý Cloudflare challenge cơ bản
- Hỗ trợ cả Chromium/Firefox

**2b. Anti-Detection**
- Random User-Agent pool (10+ UA strings thực tế)
- Random delay giữa các request (1-3 giây)
- Referer header tự động
- Accept-Language, Accept-Encoding headers

**2c. SSL/TLS Flexibility**
- Mặc định verify SSL = True
- Thêm option `--no-verify` cho self-signed certs
- Hỗ trợ custom CA bundle

**2d. Cookie & Authentication**
- `--cookie "name=value"` từ CLI
- `--cookie-file cookies.json` để load cookie session
- `--header "Authorization: Bearer xxx"` cho API tokens
- `--auth user:pass` cho HTTP Basic Auth

**2e. Proxy Support**
- `--proxy http://host:port` cho HTTP/HTTPS proxy
- `--proxy socks5://host:port` cho SOCKS proxy

- Pool 15+ User-Agent strings cập nhật (Chrome, Firefox, Edge, Safari trên Win/Mac/Linux)

## User Review Required

> [!IMPORTANT]
> **Playwright Installation**: Playwright yêu cầu chạy `playwright install` sau pip install để tải browser binaries (~300MB). Bạn có chấp nhận dependency này không? Nếu không, tôi sẽ dùng `selenium` hoặc chỉ cải thiện requests-based scraping.

> [!IMPORTANT]
> **Package name**: Hiện tại code import `web_miner.xxx` nhưng folder tên `Web-Claw`. Tôi sẽ đổi tất cả import thành relative/local import để chạy được trực tiếp trong folder. Có OK không?
